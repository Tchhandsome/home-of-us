# Home Of Us

Home Of Us 是面向两人小家庭的生活管理系统，第一版聚焦手机端快速记录、花卉养护、提醒中心、购物清单、家务、库存、账本和资料库。

## 本地开发

启动 MySQL：

```bash
docker compose up -d mysql
```

启动后端：

```bash
mvn -f backend/pom.xml spring-boot:run
```

启动移动端：

```bash
npm run dev --workspace apps/mobile
```

启动管理端：

```bash
npm run dev --workspace apps/admin
```

## 默认端口

- MySQL: `127.0.0.1:3307`
- 后端 API: `http://localhost:8080/api`
- 移动端: `http://localhost:5173`
- 管理端: `http://localhost:5174`

## 默认账号

本地第一版内置两个账号，方便手机端分开登录：

- 小谭：`小谭` / `123456`
- 丹丹：`丹丹` / `123456`

两个人登录后看到同一个默认家庭空间内的公共数据。私密空间会按当前登录成员过滤，只展示自己可见的私密记录、悄悄话和共享留言。

## 业务规则

- 购物清单加入时可以选择默认账本分类。
- 购物项完成时必须填写实际金额，可选择分类和购买人；系统会自动生成一条支出账本记录。
- 购物项会绑定自动生成的账本记录 ID，避免重复点击导致重复入账。
- 账本分类由后端接口提供默认值：餐饮、日用、花卉、交通、居家、娱乐、数码、服饰、其他。
- 图片上传第一版存储在后端本地 `data/uploads` 目录，通过 `/api/uploads/**` 访问。
- 共同相册支持手机选择图片上传，也保留图片链接作为调试入口。
- 用户资料支持编辑昵称、登录名、密码、头像、简介和头像色。
- 宠物模块支持宠物档案、宠物照片、医疗记录；医疗记录可覆盖驱虫、疫苗、体检、用药等场景。

## 当前阶段

当前项目采用模块化单体架构，不拆微服务。健康、药品和可穿戴设备接入暂不进入 V1。
