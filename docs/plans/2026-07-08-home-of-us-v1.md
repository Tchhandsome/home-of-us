# Home Of Us V1 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use executing-plans to implement this plan task-by-task.

**Goal:** 搭建 Home Of Us 第一版可运行前后端骨架，并完成家庭空间、快速记录、提醒中心、花卉系统的核心闭环。

**Architecture:** 使用模块化单体架构，后端为 Spring Boot + JDBC + Flyway + MySQL，前端为 Vue3 移动端与 Vue3 管理端。移动端优先承载快速记录和日常处理，管理端承载模块看板、统计和批量维护入口。

**Tech Stack:** Java 17、Spring Boot 2.7.13、MySQL 8、Flyway、Lombok、Vue3、Vite、TypeScript、Docker Compose。

---

## Task 1: 基础工程与本地数据库

**Files:**

- Create: `docker-compose.yml`
- Create: `.env.example`
- Create: `README.md`
- Create: `backend/pom.xml`
- Create: `backend/src/main/resources/application.yml`
- Create: `backend/src/main/resources/db/migration/V1__init_schema.sql`

**Steps:**

1. 创建 Docker Compose MySQL 服务，端口使用 `3307:3306`，避免冲突。
2. 创建后端 Maven 工程，依赖 Spring Web、JDBC、Validation、Flyway、MySQL Connector、Lombok、Test。
3. 创建应用配置，默认连接本地 Docker MySQL。
4. 创建数据库初始化脚本，覆盖家庭、成员、快速记录、提醒、花卉、购物、家务、库存、账本、附件等 V1 表。
5. 使用 `mvn -f backend/pom.xml -DskipTests -o compile` 做离线编译验证。
